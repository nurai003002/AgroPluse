# AgroPulse

Прототип для хакатона: спутник NASA подсказывает фермеру, где и когда сеять и когда беречь посевы. Советы приходят в Telegram или SMS на кыргызском и русском.

Весь сайт — один файл `index.html` (HTML + CSS + JS, без сборки и бэкенда). Библиотеки подключаются с CDN: Leaflet (карта) и Chart.js (график).

## Запуск

Локально — открыть `index.html` в браузере или:

```bash
python3 -m http.server 8080
```

На сервере — сайт и бот одной командой `docker compose up -d --build`, подробно в [DEPLOY.md](DEPLOY.md).

## Данные

- Настоящие: карта (OpenStreetMap / CARTO), спутниковая подложка (Esri World Imagery), рельеф (AWS Terrain Tiles на основе NASA SRTM), поиск сёл (Nominatim).
- Демо: значения SMAP, MODIS/Landsat и NASA POWER подготовлены заранее в формате NASA API, прогноз погоды — тоже демо.

## Telegram-бот (`bot/`)

Настоящий бот на тех же расчётах, но на живых данных:

- климат 1985–прошлый год и влажность почвы — **NASA POWER** (температура, осадки, GWETROOT);
- прогноз на 7 дней и высоты рельефа — **Open-Meteo**;
- поиск сёл и названия мест — **OpenStreetMap Nominatim**.

Фермер отправляет геолокацию или название села, выбирает культуру и получает совет: подходит ли место, когда сеять, риски недели, нужен ли полив. По кнопке «🔔» включаются утренние предупреждения (7:00 по Бишкеку): перед окном сева, заморозком, жарой и засухой.

Запуск (нужен Node.js 22+):

```bash
cd bot
npm install
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
npm start
```

Проверка расчётов без Telegram: `npm run try -- "Кемин" barley` (третий аргумент `ky` — на кыргызском).

Данные пользователей и кэш лежат в `bot/data/` (в git не попадают).
